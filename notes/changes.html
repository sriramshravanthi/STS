The face ships an opsz axis the page never used, so display type was drawn with text-grade letterforms — thicker strokes, looser spacing than the size wants. The difference is deliberately subtle; it shows most in the thin strokes and the tightness of the joins.

Change 04 · the bug that mattered most

Canonical URLs pointed at somebody else's site

The resolver rewrote every page's canonical to origin + '/'. On GitHub Pages, which serves a project from /<repo>/, that dropped the path segment — so all 22 pages declared the account root as their canonical, and every share card referenced a file that does not exist.
