01 · the one that mattered most

Every page was claiming to be a different website

The resolver rewrote each page's canonical to origin + '/'. GitHub Pages serves this repo from /STS/, so dropping the path segment pointed all 22 pages at the account root — a different site. In search terms that says "these 21 pages are duplicates, drop them".

PageBeforeAfter
index…github.io/…github.io/STS/
about…github.io/…github.io/STS/about.html
pricing…github.io/…github.io/STS/pricing.html
JSON-LD @id…github.io/#org…github.io/STS/#org

Resolved from location.pathname, so the same code is correct at /STS/ and at a future apex domain with no config change

03 · what Google and assistants read

The homepage published an organisation named "[COMPANY NAME]"

The pattern that strips unfilled placeholders had no space in its character class, so it removed [PHONE] but left [COMPANY NAME] sitting beside it. The result was worse than omitting the node: a company whose structured name was a placeholder, with its phone number correctly deleted next to it.

before   /\[[A-Z]+\]/        → 3 placeholders survived into production
after    /\[[A-Z][A-Z ]*\]/   → 0

now kept   @type, @id, alternateName "NorthKey AI", url, description,
           slogan, areaServed, knowsAbout, makesOffer, addressCountry "US"
now dropped  name, email, telephone, streetAddress   ← unverified, so absent

alternateName survives because "NorthKey AI" was never bracketed — the node keeps a usable label instead of going anonymous

check itOpen the homepage, Ctrl+U, search for ld+json →
